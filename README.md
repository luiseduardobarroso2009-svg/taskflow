# 🚀 TaskFlow

Um gerenciador de tarefas moderno, simples e responsivo, desenvolvido para organizar atividades e acompanhar o progresso do dia.

## ✨ Funcionalidades

- ✅ Criar tarefas
- ✏️ Editar tarefas
- 🗑️ Excluir tarefas
- 🔄 Marcar tarefas como concluídas
- 🔎 Filtrar tarefas
- 📊 Acompanhar progresso
- 🌙 Tema claro e escuro
- 💾 Salvamento automático no navegador
- 📱 Layout responsivo

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage
